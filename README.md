# Ndoa — International Wedding Website

A premium, responsive wedding celebration website built for the family's wedding.

## Stack
- HTML5 semantic structure
- CSS3 responsive visual system
- JavaScript
- jQuery
- Bootstrap 5
- GSAP motion
- Google Fonts
- GitHub Actions + FTP deployment

## Deployment
The GitHub Actions workflow deploys the production files to:

`/ndoa.kesug.com/htdocs/`

Credentials are read only from GitHub Actions Secrets:
- `FTP_USERNAME`
- `FTP_PASSWORD`

Never commit FTP credentials to the repository.

## Before the wedding
Replace the sample couple names, wedding date, venue, photos and event times in `index.html` and `assets/js/app.js`.
